# OpenAI DevDay 2026 発表・関連リリース一覧

[公式のDevDay 2026まとめ](https://learn.chatgpt.com/docs/whats-new/devday-2026)に掲載されている17項目と、関連リリースのDecisions APIを含む計18項目を整理した一覧です。

- 公式まとめの日付：2026年9月29日
- DevDay掲載項目の提供状況は発表時点の情報です。Decisions APIは10月6日の提供開始情報を記載しています。
- 「開始日未確認」は、9月29日に提供の案内はあるものの、初回提供日を確認できないことを表します。
- 各発表名のリンク先は、公式解説・開発者向けページです。
- Decisions APIは公式DevDayまとめには未掲載のため、関連リリースとして追加しています。
