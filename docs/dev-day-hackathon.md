​ルールについて
​成果物はウェブで公開されているものに限定します。ChatGPT Sites はもちろん、Cloudflare Workers や Vercel などにデプロイしてください。慣れていない方は事前に準備をしてくることをオススメします。

​ハッカソン中の開発には Codex CLI / Codex App / ChatGPT Workを使ってください。Claude Code などはもちろん、Cursor や Devin 経由で OpenAI のモデルを使うことも NG にします。OpenAI の OAuth を使ってサードパーティのハーネスを使うことも NG にします。

​事前に成果物を作ってくるのは NG ですが、プロトタイピングレベルであれば構いません。その場合、SNS などで公開していない新規のものだけを許可します。既に他のハッカソンで提出したもののチューンナップなどは NG とします。

​DevDay 発表関連情報について下調べするのは構いません。むしろしてください。

​審査基準は下記の 4 観点とします。

​1. 新機能の活用

​DevDay 2026で発表された機能を、目的に合った形で活用しているか？

​2. 使いやすさ

​他の人にとって使いやすいものになっているか？

​3. 有用性

​他の人にとって今後どれだけ役に立つ可能性があるか？

​4. 独創性

​着眼点や解決方法にオリジナリティがあるか？

​予選は OpenAI のモデル（GPT-6.1 Sol あるいは Decisions API を予定）による自動評価を行ないます。本戦は私が独断と偏見で決めるか、投票にするかまだ迷っています。迷い終わったらこちらに反映します。

​チーム編成について
​このハッカソンでは事前に 2 人から 4 人のチーム編成をした上で参加していただきます。当日 30 分ほど時間を用意していますが、もう少しどんな人かを知った上でチームを組みたいという方向けに、前夜祭と称して、前日の夜にチーム編成を兼ねたネットワーキングイベントを開催しますので、ぜひご参加くださいませ。
